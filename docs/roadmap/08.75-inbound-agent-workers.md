Status: Research
Priority: Deferred

Created: 2026-08-17

## Objective

Admit a remote agent that Kiln did not launch as a bounded work participant:
it reasons in its own environment against its own inference budget, proposes
changes and evidence into a lease-scoped sandbox, and settles through operator
review. Kiln keeps credential, merge, and dispatch authority on the operator
machine.

The motivating case is a chat-surface agent whose inference budget is separate
from the exhausted Codex and Claude pools. The architecture must hold for any
inbound agent, not only that one.

## The Inversion This Track Owns

Every managed child Kiln has today is outbound: Kiln launches the process,
holds its lease, observes it, and can kill it. An inbound agent connects into
Kiln and requests work surface. Kiln becomes the server rather than the
launcher.

Three consequences follow, and they are the reason this is a separate track:

- Liveness control is lost. Kiln cannot kill what it did not start, so lease
  timeout and settlement become the only control.
- Identity is asserted rather than assigned. The agent presents a credential
  instead of inheriting one from its parent.
- The reasoning environment is outside operator control. Its transcript,
  context, and tool history are not observable evidence.

The searched 2026 sources on MCP authorization, agentic CI, and durable
execution all assume the platform launches the agent. This inversion is not
covered by existing practice and must be designed rather than adopted.

## Ownership

This track owns inbound agent identity, admission of a non-operator principal,
the bounded verification surface, lease-scoped sandboxes for inbound work,
proposal intake, and settlement of work Kiln did not launch.

Roadmap 08 owns operator pairing, device identity, operator sessions, scopes,
expiry, and revocation. Roadmap 08.5 owns reachability, transport adapters, and
connector lifecycle. This track consumes both and owns neither.

**An agent identity never becomes an operator identity.** This mirrors the
existing rule that transport identity never becomes operator identity. An
inbound agent cannot pair a device, mint or widen an operator session, approve
its own work, select a provider credential, or dispatch to another route.

Core and Runtime retain route admission, economic commitment, credential, tool,
approval, and merge authority. Gateway contracts own serializable shapes.

## Architecture

### Reasoning and execution are separate planes

The remote agent reasons and proposes. A credential-holding local plane
verifies and applies. Never one process.

This is not a workaround for a missing capability. It is the documented
mitigation for prompt injection against agents that touch repositories: a model
that produces a structured recommendation but cannot execute it cannot be
weaponized into stealing credentials or pushing code. GitHub's own agentic
workflow product enforces the same split, withholding write credentials from
the agent and validating emitted artifacts in an isolated job before any scoped
write.

The threat is demonstrated rather than theoretical. GitHub's official MCP server
carried a prompt-injection flaw permitting repository read and write, and
published attack research covers this class in CI pipelines directly. For an
agent that reads issue text, review comments, and test fixtures, a poisoned
fixture is remote code execution rather than a wrong answer.

### Untrusted input never reaches a credentialed context

Repository text, issue bodies, review comments, and fixtures are data. They are
never instruction. Any path that lets ingested content influence a credentialed
operation is a defect regardless of how the content is framed.

### Authority is tool-level policy bound to an agent identity

Server-level admission is insufficient. The failure mode named in current MCP
practice is exactly this: where a platform cannot limit which tools a client may
invoke, the result is broad agent authority with poor blast-radius control.

Kiln already expresses this through `propose` and `approved-write` access plus
the configured tool and resource scopes; that authority is simply not projected
over an inbound surface yet. Access levels become the bounded authority
vocabulary rather than a new permission model.

Enforcement is per call and fails closed.

### Verification is a tool that returns a verdict

The bounded surface exposes operations, never a shell:

```text
typecheck_package(package)        -> { errors, diagnostics }
run_tests(package, files?)        -> { passed, failed, skipped, total }
mutation_check(file, line,
  replacement, expected_test)     -> { passed_clean, failed_when_mutated }
pre_existing_failure(test)        -> { fails_on_clean_tree }
diff(lease)                       -> { files, insertions, deletions }
```

A shell would return stdout the agent narrates. A verdict is evidence the agent
cannot restate. This distinction is load-bearing: across six delegated
admissions under Roadmap-adjacent work on issue #85, five reports mislabelled
the delegate's own regression as pre-existing, and one reported no vacuous
assertions while having deleted an ordering guarantee. `pre_existing_failure`
and `mutation_check` convert both of those claims into machine-produced facts.

### Sandboxes are leases that must settle

An inbound sandbox is a lease with an id, an isolated worktree, a working
directory mode, a timeout, and a cleanup status. It settles as adopted,
rejected, or abandoned. An unsettled lease is a defect, not a loose end.

`OperatorManagedAgentResourceLeaseSnapshot` already models
`workingDirectoryMode` including `isolated-worktree` and `sandbox`, and the
managed-account-lease settlement discipline already exists. This track extends
that discipline to a participant Kiln did not launch, where timeout is the only
liveness control.

Current durable-execution platforms supply retries and replay but do not gate
external effect settlement on per-resource progress. Adopting one of them does
not solve settlement; Kiln's existing lease discipline is ahead of that tooling.

### Merge authority is local and human-gated

The agent proposes a branch and a structured evidence object. The operator
plane runs the real gates and merges. Review is the step that has caught every
defect delegation has produced so far, including a regression that silently
disarmed a write-authority test.

## Sandbox Selection

Deferred to an evidence-backed decision, not chosen here. The relevant axis is
that per-execution microVM isolation is optimized for short-lived runs, while a
bun monorepo with `tsc -b` project references needs installed dependencies and
warm state across iterations. Persistent-environment providers are positioned
for build-test-iterate agents; microVM providers offer stronger kernel
isolation per call. A lease-scoped worktree holding no credentials already
bounds blast radius, which changes the weight of that tradeoff.

An operator-hosted sandbox on the development machine remains admissible and
requires no third-party provider. It is the correct first proof.

## Non-Goals

- No inbound agent obtains an operator session, device pairing, or approval
  authority.
- No raw shell, filesystem, or process tool over an inbound surface.
- No credential material inside a sandbox.
- No merge, force-push, or protected-branch write by an inbound principal.
- No Kiln-hosted cloud, and no managed relay by scope creep.
- No treatment of a delegate's self-report as verification evidence.
- No dependency on a specific third-party sandbox provider before measured need.

## Slices

### Slice 0 - Terms And Premise

Status: Closed conditionally positive, 2026-08-17.

The provider prohibits automatic or programmatic extraction of output, and
prohibits circumventing rate limits or configuring the service to avoid usage
limits. It does not prohibit interactive use of a shipped connector feature.

The admissible shape follows directly:

- **Admissible.** A human-initiated session in which the operator states a task
  and the agent works through official connector tooling against a bounded
  surface, with the operator reviewing the result. This is interactive use of a
  shipped feature, not extraction.
- **Inadmissible.** Any scripted or automated driving of a chat surface,
  including browser automation that submits prompts and harvests output, or any
  arrangement whose purpose is to exceed what an interactive session consumes.

This constrains the design rather than blocking it: the inbound worker is
operator-initiated by construction, and no slice in this track requires
automating a chat surface. Should a later slice require unattended operation,
the premise reopens and must be re-decided rather than assumed.

Residual, recorded rather than resolved: operating several own-account
subscriptions in sequence to extend working capacity sits in an ambiguous
region of the usage-limit clause. Owning multiple accounts is ordinary and no
credential is shared, so this is a disclosed risk the operator carries
knowingly, not a finding against the design. A team plan is the unambiguous
path if capacity becomes a sustained constraint.

This finding is a documentation review, not legal advice.

### Slice 1 - Bounded Verification Surface

Expose the verification operations above as a separate bounded context with its
own projection, consumable locally before any remote principal exists. Value
lands immediately: local and outbound delegates gain machine-checked evidence
for the claims that have proven unreliable.

Do not extend the existing control-plane MCP surface; keep dependency direction
clean and avoid coupling this to unrelated open defects in that surface.

### Slice 2 - Inbound Agent Identity

Define the inbound principal, its credential, its binding to an access level,
expiry, and revocation, consuming Roadmap 08 contracts without
widening them. Prove the negative: an agent credential cannot produce an
operator session.

### Slice 3 - Lease-Scoped Sandbox And Settlement

Materialize an isolated worktree per inbound lease, with timeout, cleanup, and
explicit settlement. Prove orphan recovery when the agent never returns, which
is the failure mode that has no process to kill.

### Slice 4 - Proposal Intake And Review

Accept a branch plus a structured evidence object, run the real gates locally,
and present an adoption decision. Evidence is the handoff; prose is not.

### Slice 5 - Bounded Dogfood

Run one real bounded task end to end through the complete path and record
residual risk honestly, including what the operator plane caught that the
delegate reported clean.

## Verification

Negative-authority tests proving an agent credential cannot mint or widen an
operator session, cannot reach a protected branch, and cannot invoke a tool
outside its access level. Lease timeout, orphan recovery, and cleanup
fixtures. Verdict-tool contract tests including the case where a mutation does
not produce a failure. Prompt-injection fixtures carrying instruction-shaped
content in fixture, issue, and comment positions, proving no credentialed
operation is influenced. Affected package tests, typecheck, and
documentation-link verification.

Live inbound tests require explicit operator authority and cleanup evidence.
Source tests do not prove a remote agent behaves correctly.

## Completion Criteria

A remote agent Kiln did not launch can take a bounded task, work in a
lease-scoped sandbox with no credentials, produce machine-checked evidence that
its changes preserve detection power, and hand back a proposal that the
operator plane verifies and merges. Its identity never becomes operator
identity, its lease always settles, and a poisoned repository artifact cannot
reach a credentialed operation. The economic premise is either proven under
provider terms or the track is closed with that finding recorded.

## Residual Risk

The reasoning plane is unobservable. Kiln sees proposals and evidence, not the
agent's context or tool history, so evidence design carries the entire
verification burden.

Liveness has no process-level control. Timeout and settlement are the only
mechanisms, and they must be exact.

No searched source addresses inbound agents specifically. This design extends
Kiln's existing lease and admission discipline into territory current practice
does not cover, so it should be treated as unproven until Slice 5 produces
evidence.
