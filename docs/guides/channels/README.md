# Channel and tool guides

Use these guides to connect external inputs, expose tools, and run Kiln through
supported protocol surfaces.

| Goal | Guide |
| --- | --- |
| Connect messaging or webhook channels | [Channel adapters](channels.md) |
| Run Kiln as an application AI runtime | [Gateway application runtime](gateway-app-runtime.md) |
| Expose the canonical control plane through MCP | [Canonical MCP](mcp.md) |
| Configure and operate tool execution | [Tool use operations](tool-use.md) |
| React to lifecycle events | [Hook system](hooks.md) |
| Start work from schedules or external events | [Triggers](triggers.md) |

For the boundary between these surfaces, see
[Runtime surfaces](../../architecture/surfaces/runtime-surfaces.md).
