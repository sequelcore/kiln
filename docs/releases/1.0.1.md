# Kiln 1.0.1 -- Packaging Graph Fix

Kiln `1.0.1` fixes the npm publish graph introduced by `1.0.0`.

`1.0.0` established the new control-plane baseline, but the publish workflow
did not include the full package graph needed by downstream consumers. This
release corrects that without changing the architectural thesis of the `1.x`
line.

## Highlights

- `publish.yml` now publishes the required tools packages and `@kilnai/tui`.
- The workflow now builds `@kilnai/tools` and `@kilnai/tui` before publish.
- `workspace:*` references are now resolved across all public workspace
  packages before `bun publish`.
- Workspace package versions were bumped to `1.0.1`.

## Why this matters

The critical fix is that downstream consumers such as `kiln-gateway` can now
resolve the published package graph instead of failing on missing or unresolved
workspace dependencies.

## Verification

The `1.0.1` workspace passed:

- `bun run typecheck`
- `bun run test`
- `bun run build`
