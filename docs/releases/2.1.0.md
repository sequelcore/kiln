# Kiln 2.1.0

Status: supported public release.

Kiln 2.1.0 makes the official GUI/TUI/CLI operator surfaces usable from a
normal public npm installation instead of relying on a source checkout.

## Highlights

- Publishes `@kilnai/gui` as the public GUI static asset package.
- Makes `@kilnai/cli` the global install boundary for CLI, GUI, TUI, runtime,
  gateway contracts, and GUI assets.
- Serves GUI assets from the installed `@kilnai/gui` package by default.
- Keeps GUI dev mode explicit with `kiln gui --dev` for source-tree work.
- Publishes GUI before runtime and CLI in the release workflow so runtime can
  depend on the public asset package.
- Keeps Native out of the global install contract until its distribution model
  is designed separately.
- Adds governed heterogeneous teams to the existing managed orchestration
  lifecycle. Each work item preserves its admitted agent profile, route, and
  dependencies; successful bounded handoffs flow downstream and failed
  dependencies block their consumers.
- Requires distinct provider/model identities for independent review and ships
  the `kiln-managed-frontend-team` benchmark profile for structural team
  composition and handoff evidence.

## Install

```bash
bun add -g @kilnai/cli@2.1.0
kiln auth codex login
kiln gui
kiln tui
```

## Verification

Release verification:

```bash
bun install --frozen-lockfile
bun run typecheck
bun run test
bun run build
```
