# Kiln 1.0.3 -- Release Line Correction

Kiln `1.0.3` makes the `1.x` release line consistent across git tags, npm
package metadata, and the publish workflow.

`1.0.0` established the control-plane baseline. `1.0.1` and `1.0.2` corrected
the publish pipeline. `1.0.3` is the first tag in that sequence where the git
tag and published package versions are intentionally aligned.

## Highlights

- Workspace package versions were bumped to `1.0.3`.
- The publish workflow now:
  - publishes the full required package graph
  - builds packages before publishing them
  - rewrites `workspace:*` references safely before `bun publish`
- This release supersedes the inconsistent `v1.0.2` tag for downstream
  consumers.

## Why this matters

Downstream repos such as `kiln-gateway` can now target a version whose git tag,
publish pipeline, and npm metadata all agree.

## Verification

The `1.0.3` workspace passed:

- `bun run typecheck`
- `bun run test`
- `bun run build`
