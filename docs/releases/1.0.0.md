# Kiln 1.0.0 -- Control Plane Reset

Kiln `1.0.0` marks the first release aligned to the new product thesis:
Kiln is a cybernetic control plane for governed AI work, not an orchestration
engine, meta-orchestrator, or literal biological identity.

## Highlights

- Public architecture and research docs were rewritten to establish the new
  doctrine as source of truth.
- The orchestrator boundary was simplified and split into clearer support
  modules for checkpointing, interrupts, developer tools, memory sync, and
  verification.
- Legacy swarm-era surfaces were removed from the active product boundary:
  `SwarmStrategy`, `TeamComposer`, and `swarm` as an official `TeamMode`.
- Active coordination names now reflect the new architecture:
  `DemandAllocator`, `ChainGovernor`, and `TaskRegistry`.
- Workspace package metadata was updated to reflect the control-plane identity.

## Compatibility

This release intentionally resets the architectural baseline, but it is not the
end of the refactor.

Additional breaking changes are expected in future releases as the remaining
bounded contexts are aligned to the same doctrine, especially around:

- runtime/session boundaries
- engine contracts
- memory and knowledge alignment
- safety, tools, and sandbox boundaries

That next wave is paused for now while development focus moves to a different
project built on top of this cleaner base.
