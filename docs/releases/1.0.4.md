# Kiln 1.0.4 -- Timezone Scheduling Fix

Kiln `1.0.4` fixes timezone-aware cron scheduling in the core engine.

This release corrects a runtime bug where named IANA timezones could fail to
produce the next scheduled fire time, causing scheduled triggers to crash
during gateway startup.

## Highlights

- Fixed timezone-aware `nextFireTime()` evaluation in the cron domain.
- Preserved existing behavior for schedules without an explicit timezone.
- Added focused tests for:
  - `America/Tijuana`
  - UTC evaluation
  - named timezone scheduling behavior

## Why this matters

This release removes the scheduler crash that prevented `kiln-gateway` from
starting cleanly when an app declared scheduled triggers under a named
timezone.
