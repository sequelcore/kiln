# Kiln 2.0.0

Status: supported public baseline.

Kiln 2.0.0 is the first supported public baseline for the current
biocybernetic control-plane architecture.

## Highlights

- Establishes the supported package baseline as `2.0.0` across the workspace.
- Keeps active documentation centered on architecture, guides, roadmap, and
  supported release notes.
- Publishes from `v2.*` tags only, with tag/package version validation before
  npm publish.
- Ships the public package graph including gateway contracts, core, runtime,
  React SDK, CLI, TUI, and widget.
- Keeps reserved developer-tool platform packages private until Kiln ships
  actual vendored binaries.

## Verification

Release verification:

```bash
bun install --frozen-lockfile
bun run typecheck
bun run test
bun run build
```
