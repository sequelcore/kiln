# Formal Screening Limitations

Current studies are diagnostic, not evidence for enabling formal verification
by default. Development exposure, correlated reference/oracle construction,
translator subset failures, visible postconditions, and a control ceiling limit
causal interpretation. Isolated qualification success does not erase recorded
concurrent timeout failures.

Use synthetic portable fixtures for product tests. Do not copy private cases,
operator paths, external responses, or raw reports into the repository or a
published package.
