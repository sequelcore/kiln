# Verified Efficiency Reference Limitations v1

- The fixture is deterministic and synthetic; it does not measure a provider,
  model, or external harness.
- Token values demonstrate contract behavior and must not be quoted as
  production savings.
- Cost is non-comparable because no metered provider call occurs.
- The bundle does not estimate nondeterministic model variance.
- External harness comparisons require their own committed fixtures, exact
  versions, provider/model identities, authority and tool snapshots, failed
  cases, confidence bounds, and vendor limitations.
