# Operations runbooks

Runbooks cover stateful service and publication procedures. Review the stated
prerequisites and mutation boundary before executing a command.

- [Operate the Model Gateway](model-gateway.md) covers setup, verification,
  recovery, retained incidents, and exact uninstall.
- [Release runbook](release.md) defines the publication process. No release
  candidate is currently authorized.

For routine repository and operator tasks, use the
[operations guides](../guides/ops/README.md).
