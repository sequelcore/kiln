# Kiln Biological Research Program

## Goal

Research biological, neurological, biocybernetic, and cybernetic systems that
can become real Kiln architecture.

This program is not for aesthetics.

Every stage must produce:

- mechanisms, not vibes
- software abstractions, not metaphors
- direct Kiln mappings
- invariants, control loops, memory policies, or state machines
- explicit limits of the analogy

## How To Use This Program

Each numbered file contains a self-contained research prompt with full Kiln context.
Copy the prompt from inside the code fence, paste it into your external research tool,
then overwrite the file with the research output.

`BIO_RESEARCH_PROMPTS.md` is no longer needed — all prompts live in their respective files.

You do not have to complete the entire program in one pass.

Use this order:

1. `01-global-framing.md`
2. `18-reading-list-generator.md`
3. `03-nervous-system-routing-control.md`
4. `05-layered-memory-architecture.md`
5. `08-homeostasis-resource-regulation.md`
6. `07-immune-system-safety-threat-detection.md`
7. `09-swarm-coordination-intelligence.md`
8. `10-fungal-distributed-context-substrate.md`
9. `11-morphogenesis-growth-differentiation.md`

finish the first 4 to 6 stages.

`04-neuroscience-attention-salience.md` and

their parent areas are already understood.

## Research Discipline

Reject any output that:

- sounds profound but does not define a mechanism
- cannot map to state, signals, memory, or control
- uses biology only as branding
- hides uncertainty
- does not say where the analogy fails
