# 18 Reading List Generator

## Research Prompt

```
You are a senior research architect creating a research reading plan for Kiln's biological architecture.

Kiln is an AI orchestration engine (Bun/TypeScript) that uses biologically-grounded primitives:
- ThresholdAllocator (ant colony response-threshold model)
- CascadeController (neural field theory energy model)
- TaskChannel (stigmergy publish/claim/complete)
- TeamComposer (domain-driven team templates)
- Memory with decay and compaction
- Safety pipeline (layered defense)
- Model routing (complexity scoring, capability matching)
- EventBus (43 typed events as sensor fabric)

The goal is to find biological, neurological, and cybernetic mechanisms that can become real software invariants, control loops, memory models, or routing systems inside Kiln.

Constraints:
- prioritize high-leverage fields only
- separate foundational material from advanced material
- favor papers, textbooks, and canonical surveys over pop-science

Organize the reading plan into:
1. Neuroscience and memory
2. Immune systems
3. Homeostasis and control
4. Swarm / stigmergy
5. Fungal networks
6. Cybernetics

For each section provide:
- what to read first
- what concept it will help me build inside Kiln
- what not to over-interpret

End with these sections:
- Mechanisms
- Software Abstractions
- Direct Kiln Mappings
- Risks / Misuse
- Where The Analogy Breaks
- Actionable Research Follow-Ups
```
