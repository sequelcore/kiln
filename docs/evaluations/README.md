# Evaluations

This directory contains dated empirical evidence: experiments, route and model
assessments, benchmark inputs, and smoke reports.

Evaluations describe what was observed under a specific fixture, version,
provider, model, harness, configuration, authority envelope, and evidence
cutoff. They do not define current policy or stable architecture.

Current route and provider policy belongs in executable configuration. Stable
benchmark requirements belong in
[benchmark architecture](../architecture/quality/benchmark-validation.md).
Public claims require the evidence gates defined there.
